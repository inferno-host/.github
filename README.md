# Inferno-host 🔥

## Проблема
Периодически возникает необходимость развертывать небольшие приложения. Однако помимо того, что разработка логики занимает значительное время, дополнительное время расходуется на бюрократические процессы: создание репозитория, аренда виртуалки, настройка деплоя, отсутствие бойлерплейтов и инструментов мониторинга.

## Цели
- Создать монорепозиторий/монолит с готовым бойлерплейтом и структурой проекта для упрощения деплоя
- Изучение методик Infrastructure as a Code
- Освоение Kubernetes
- Реализация возможности создания и удаления всей инфраструктуры и приложений "по кнопке"

## Компоненты
- **Terraform**
- **MySQL**
- **Container Registry**
- **Kubernetes**
  - ArgoCD
  - Prometheus
  - Loki
  - Grafana

*Вся инфраструктура разворачивается в DigitalOcean.*
